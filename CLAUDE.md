# VitaScore — правила проекта

## Стек
- Python 3.11+, Flask, SQLite через стандартный модуль sqlite3 (без ORM).
- Фронтенд: чистые HTML/CSS/JS, без фреймворков и сборки.
- Зависимости только: Flask, pytest (и gunicorn для деплоя). Новые библиотеки — только с моего согласия.

## Ограничения
- Авторизация — только своя, по e-mail и паролю (app/auth.py). НЕ добавлять OAuth, сторонние API и новые внешние сервисы.
- Все POST-формы — с csrf_token; страницы кабинета — через @login_required; данные клиента выбирать только по g.user["id"].
- Яндекс.Метрику и виджет aistudio.yandexcloud не менять, кроме одного: Метрика и собственный лог событий
  включаются только после согласия на аналитические cookie (cookie vs_consent=all, см. app/consent.py).
- Новые cookie, трекеры и поля с персональными данными — только вместе с обновлением app/templates/privacy.html
  и POLICY_VERSION в app/consent.py.
- Дизайн и тексты страницы не менять, кроме блока анкеты.
- Ответы анкеты — данные о здоровье: /api/score без health_consent=true не считает и не хранит.
- Соглашения: /terms (TERMS_VERSION), /consent/health и /privacy (POLICY_VERSION) в app/consent.py; реквизиты
  оператора — только в app/templates/_operator.html. Новые данные о здоровье — вместе с текстом /consent/health.
- Красные флаги показывать всегда (не прятать за тарифом); формулировки — «обсудите со специалистом», не диагноз.

## Структура
- app/scoring.py — скоринг по методике docs/methodology-v2.0.md (три вложенных уровня: короткий/ядро, средний,
  расширенный), без импорта Flask. Единственный источник вопросов, условий показа, таблиц баллов, флагов и шагов:
  анкета на главной и страница /methodology строятся из него. Любая правка вопросов, баллов, весов или порогов —
  только вместе с METHOD_VERSION и docs/. Вопросы короткого уровня не менять — на них держится сравнимость ядра.
- Опросники с лицензией (LICENSED_INSTRUMENTS: SCI, STOP-Bang, MEPA) не включать без письменного разрешения.
- app/scoring_v1.py, app/scoring_v0.py — прежние версии, только для показа старых результатов. Не менять.
- app/results.py — сохранённая оценка → данные для страниц (все версии методики).
- app/db.py — подключение к SQLite, создание таблиц и миграции (_migrate).
- app/consent.py — cookie согласия и версия политики.
- app/visitor.py — разбор User-Agent, примерная страна, источник перехода; без Flask и без сторонних библиотек.
- app/routes.py — страницы и API.
- app/auth.py — регистрация, вход, CSRF, лимит попыток. Гостевые расчёты к аккаунту НЕ привязывать — только сделанные после входа.
- app/account.py и static/js/account.js — личный кабинет: интерактивная история, рекомендации, профиль, удаление.
- app/templates/, app/static/css/, app/static/js/ — фронтенд.
- tests/ — pytest.
- index.html, 404.html в корне — только редирект со старого GitHub Pages на новый адрес, не часть приложения.

## Команды
- Запуск: python run.py  (http://localhost:5000)
- Тесты: pytest -q
- Отчёты: sqlite3 instance/vitascore.db < reports.sql

# VitaScore

Одностраничный сайт сервиса скоринга здоровья.

## Что внутри

- Адаптивный лендинг на русском языке
- Понятная презентация продукта и тарифов
- Мини-интерактив «Как вы себя чувствуете сегодня?»
- Диалог выбора тарифа
- Без зависимостей и сборки: достаточно открыть `index.html`

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages для ветки по умолчанию.

> VitaScore не является медицинским сервисом и не заменяет консультацию врача.

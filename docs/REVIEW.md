# Ревью Del Health (октябрь 2026)

Что смотрелось: бэкенд (Flask, SQLite), шаблоны, CSS/JS, тесты, приватность, доступность, производительность, процесс.
Метод: чтение кода, проверка заголовков и страниц через тестовый клиент, аудит наложений текста на 320–1440 px, сквозной прогон анкеты в браузере.

## Что сделано хорошо
- Расчёт отделён от Flask (`app/scoring.py`), покрыт тестами (183), методика версионируется, прежние версии не пересчитываются.
- CSRF на всех формах, доступ к данным только по `g.user["id"]`, лимит неудачных входов, безопасный `next`, удаление аккаунта по паролю.
- Аналитика и Метрика включаются только после согласия на cookie; согласие на данные о здоровье обязательно для расчёта.
- Доступность: контраст ≥ 4.5:1, статус уровня словом, видимый фокус, skip-link, `prefers-reduced-motion`, alt у всех изображений, один `h1` на странице.

- **Фото**: `calm-1100` и `walk-1600` самые тяжёлые; для первой отрисовки добавить `<link rel="preload" as="image">` для hero, остальным оставить `lazy`.

## Продукт и рост
1. **Возврат**: основная метрика успеха — повтор через 2–4 недели, но напоминаний нет. Напоминание по e-mail «пора повторить» даст больше всего возвратов.
2. **Результат гостя не сохраняется** в аккаунт (решение принято сознательно). Компромисс: после регистрации предлагать пройти анкету ещё раз за 3 минуты и показывать заранее, чем это полезно.
3. **Тарифы без оплаты**: сейчас только заявка. Если оплата планируется, подготовить эквайринг, оферту и возвраты до рекламы.
4. **Доверие**: нет страницы «О нас» с реальными людьми и экспертами; без выдумывания отзывов — достаточно честного описания методики, источников и контактов.
5. **Метрики**: описать воронку (главная → старт анкеты → шаги → расчёт → регистрация) и ориентиры отсева по шагам; события уже есть (`quiz_step`, `quiz_answer`).
6. **Язык**: интерфейс на русском; если рассматривается англоязычная версия, выносить тексты в словари заранее.
7. **Экспорт и удаление данных**: удаление отдельных оценок и аккаунта есть; экспорт отключён по решению владельца — учесть требование о выдаче данных по запросу субъекта.

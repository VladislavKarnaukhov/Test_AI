# Изображения

Фотографии предоставлены владельцем проекта (Влад) как арт-референсы и материалы для сайта; файлы лежат в `app/static/img/` в оптимизированном виде (WebP, несколько ширин для `srcset`).

| Файл | Где используется | Исходник |
|---|---|---|
| `run-*.webp` | главный экран (бегунья на закате) | предоставлено владельцем |
| `sleep-*.webp` | глава «Сон» | предоставлено владельцем (`кровать.avif`) |
| `mountain-*.webp` | глава «Движение» | предоставлено владельцем (`закат на горе.avif`) |
| `calm-*.webp` | глава «Психологическое состояние» | предоставлено владельцем (`фото йоги.avif`) |

**Лицензии не подтверждены.** До коммерческого запуска нужно проверить и записать здесь источник и лицензию каждого снимка (например, Unsplash/Pexels или собственная съёмка). Если лицензия не подходит — заменить файл с тем же именем, вёрстка не изменится.
